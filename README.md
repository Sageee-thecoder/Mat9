# 🧮 Matematik Fonksiyonlar Projesi: Python Hesap Makinesi


Öncelikle, bu projenin yapımında Yapaz Zeka/AI (Artificial Intelligence) kullanımı olmamıştır.


Matematik dersindeki **Fonksiyonlar** konusu için hazırladığım basit bir hesap makinesi projesi. 

Amacım derste öğrendiğimiz fonksiyon mantığını kod yazarak göstermekti. Matematikte bir fonksiyona nasıl **girdi (input)** verip kurala göre **çıktı (output)** alıyorsak, burada da kullanıcıdan `sayi1` ve `sayi2` değişkenlerini (girdileri) alıp seçilen işleme göre ekrana sonucu (çıktıyı) yazdırıyoruz.

## Neler Yapabiliyor?
* Toplama (`+`), çıkarma (`-`), çarpma (`×`, `x`, `*`) ve bölme (`÷`, `/`) işlemlerini yapıyor.
* Farklı klavye kullanımları için çarpma ve bölmede birden fazla işareti tanıyor.
* Matematikte tanımsız olduğu için sıfıra bölme yapmaya çalışırsanız uyarı veriyor.
* Kodun içinde değişkenlerin ve operatörlerin matematikteki karşılıklarını anlattığım kısa notlar da yer alıyor.

## Nasıl Çalıştırılır?
Bilgisayarınızda Python yüklüyse dosyayı indirip terminalden şu komutla çalıştırabilirsiniz:

```bash
python dosya_adin.py
```

## Örnek Çıktı
```text
Sayı giriniz: 12
Bir işlem işareti giriniz (e.g: +, -, ÷,  /, ×, x....): x
Sayı giriniz: 5
Sonuç:  60
```
